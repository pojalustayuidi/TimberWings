# Документация TimberWings

Дата базового аудита: 18.11.2026. Срез: [9afd413](https://github.com/pojalustayuidi/TimberWings/tree/9afd4132335022fd5c13dff2dceea560c4ef381e). Это исходная точка для исправлений, не подтверждённый стабильный релиз.

## Источники истины

- [GDD](GDD.md) — существующие игровые системы, мир, сюжет.
- [BALANCE](BALANCE.md) — значения из GameBalance, WorkerBalance и других проверенных классов.
- [ARCHITECTURE](ARCHITECTURE.md) — инженерный справочник.
- [BUILD_QA](BUILD_QA.md) — ручные и сборочные проверки.
- [ROADMAP](ROADMAP.md) — единственный список крупных задач, статусы, критерии.
- [SIMULATOR_UPDATE](SIMULATOR_UPDATE.md) — будущие изменения, пока только дизайн.
- [CHANGELOG](CHANGELOG.md) — принятые изменения, не ежедневный дневник.
- [WORKFLOW](WORKFLOW.md) — правила ведения проекта.

## Статусы достоверности

**В коде** — найдено в исходниках. **Проверено** — подтверждено тестом на конкретном SHA. **Известный дефект** — сообщён разработчиком, причина может быть неизвестна. **План** — будущее предложение. **Требует проверки** — данные сцены, Inspector, бинарных/LFS-ассетов или поведение в билде не подтверждены.

Числа в коде и Inspector могут расходиться; при расхождении фиксируем фактическое поведение в QA. Не переносить планы в GDD текущей версии до реализации и проверки. Старый `Assets/_Project/Scripts/AI_CONTEXT.md` содержит полезные технические заметки и устаревшие этапы (например, остров на стадии блокаута). Читать его только как исторический контекст. Приоритет у настоящего комплекта, затем у проверенного кода/сцены.
