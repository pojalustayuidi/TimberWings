# Сборка и контроль качества

## Исходная точка

18.11.2026. Со слов разработчика в Unity глава в целом проходилась; в отдельном билде карта отличается/не запекается и финал может зависнуть. Исторический проход около 40 минут — ориентир, не подтверждённая метрика новой версии. На 9afd413 в рамках аудита Unity/standalone не запускались. Компиляция, Editor Play Mode, Development Build и обычный билд — разные проверки.

## Подготовка

- [ ] Чистый checkout нужного SHA; git lfs pull, git lfs status; целостность больших сцен/ассетов.
- [ ] Unity 6000.3.10f1; импорт пакетов, Console: 0 ошибок, записать warnings.
- [ ] Build Profiles: MainMenu как старт, MainLevel и все нужные сцены включены, тестовые исключены из релиза; URP renderer и shader refs.
- [ ] Проверить запечённые активы, материалы карты, портал, видео, озвучку; не полагаться на Editor-only зависимости.
- [ ] Development Build для диагностики; финальный обычный Windows build. QA shortcut к мосту не заменяет полного прохода.
- [ ] Зафиксировать SHA, Unity, дату, настройки качества, разрешение, платформу, путь к билду и логам.

## STAB-01 — карта (P0)

- [ ] Сравнить Play Mode и standalone одной ревизии.
- [ ] Новый старт: миникарта и большая карта, река, контур, игрок, актуальная задача.
- [ ] Zoom/pan, открытие и закрытие окна; 1280×720, 1920×1080, разные настройки качества.
- [ ] После стройки карта обновляется, закрытые здания/секреты не раскрываются заранее, туман открытия сохраняется.
- [ ] Мост и дальний остров после открытия; нет пустой RenderTexture, розовых материалов или ошибок.
- [ ] Установить причину: проверить stripping, материалы, ссылки на камеры и RenderTexture, Editor-only зависимости. Сохранить скриншоты/Player.log, не считать гипотезу диагнозом.

## STAB-02 — финал (P0)

- [ ] Третья стадия моста, камера не проваливается под остров, герой проходит.
- [ ] Активировать камень/портал; ролик и титры до конца; последняя цель завершена ровно один раз.
- [ ] Повторить с кликом/пробелом, удержанием Esc, ошибкой/отсутствием видео (fallback).
- [ ] Нет бесконечной блокировки ввода, пустого экрана, повторной награды, вечной цели; карточка и возврат работают.
- [ ] Save/Continue до моста, после моста, до портала и после завершения. New Game не наследует финальный флаг.

## STAB-03 — рынок (P1)

- [ ] Продажа 1 и многих брёвен/досок; до/после инвентаря, монет, итогового UI и popup. Одна операция = одно отображение.
- [ ] Быстрые повторные клики, бонусы оптовой/базарной продажи, округления, нулевой остаток; не менять реальную цену без доказательства бага логики.

## STAB-04 — UI (P1)

- [ ] Главное меню, настройки (язык, звук, ползунки, кнопки), HUD, рюкзак, карта, строительство, прокачка, навыки, работники, питомцы, достижения.
- [ ] 1280×720, 1920×1080, 2560×1440, нестандартное соотношение сторон; текст, клики, focus, UI scale, мышь/клавиатура.
- [ ] Один EventSystem, Esc закрывает верхнее окно, ввод и камера возвращаются, HUD не перекрывает важные цели. При zoom рюкзак и его элементы не мешают.

- [ ] New Game: интро, Мира, костёр, припасы, улучшение вместимости.
- [ ] Хижина, пила, 6 досок, рынок, первая продажа.

- [ ] Анимации Лео: ходьба, бег, рубка, топор, стройка, уровень, осмотры, переход обратно к движению; нет дрожания и зависания.

- [ ] Проверить DrawGizmo/EventSystem, лишние активы и архивы; отдельно проверять ссылки GUID перед удалением.

## Шаблон прогона

Дата / SHA / билд / среда / сценарий / expected / actual / PASS-FAIL-BLOCKED-NOT RUN / доказательство (скрин, видео, Player.log). Windows Player.log искать в LocalLow соответствующих CompanyName/ProductName. Тестовые сейвы изолировать; не сбрасывать настоящий прогресс.

## Release gate

P0 закрыты без исключений, P1 закрыты или явно приняты; карта и финал PASS в обычном билде, минимум один непрерывный чистый проход и проверка загрузки, отчёт сохранён. P2 документировать. Только после этого ставить стабильный tag.
