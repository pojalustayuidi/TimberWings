# Simulator Update — рабочий дизайн-бриф

**Статус:** не утверждён, реализация заблокирована до STAB-06. Сохранены договорённости прошлого обсуждения и гипотезы. Текущие механики — GDD и BALANCE.

## Цель

Глава I — Лесоруб: 3–5 часов содержательной игры. Игрок постоянно понимает, зачем прокачиваться: новые топоры, зоны, кейсы питомцев, паки работников, способы добычи и производства, сюжетные открытия. Мост — закономерный финал развития, не стена из бесконечных повторов. Глава II — Шахтёр, отдельное обновление/глава.

## Принципы

- Не растягивать старый мост увеличением цен: время создают новые решения и события.
- Три жизнеспособные стратегии: личная рубка, автоматизация/работники, питомцы/синергия. Допускаем смешивание. Каждое вложение заметно улучшает игровой процесс.
- Рюкзак должен облегчать переноску; рассмотреть отмену или значительное снижение штрафа от заполненности.
- Рубка сохраняет третье лицо. Действия дают хороший feedback, QTE не превращается в принудительные повторные нажатия.
- Сохраняем сюжет, атмосферу, стилистику. Обучение постепенное, без перегрузки UI.
- Кейсы за игровую валюту — коллекция с гарантиями/альтернативами. Не требовать удачного редкого дропа для основной цепочки.

## Идеи для обсуждения (не утверждённые правила)

| Модуль | Предложения |
|---|---|
| Рубка | Валка дерева, обработка ствола, сбор; виды по выходу и времени, бонус точного удара, редкие деревья |
| Топоры | Отдельные модели и качества, сила, скорость и специализация, видимая ценность |
| Рюкзак | Уровни/модели, меньше штрафов, удобная разгрузка и логистика по мере развития |
| Производство | Очереди, склады, автоматическая подача/распил позднее, возможные дополнительные рецепты |
| Экономика | Цены, стоимость времени, заказы/контракты, альтернативные источники денег и расходы |
| Работники | Сохранить базовые профессии, рассмотреть лесника, перевозчика, мастера, рабочие места, перки и уровень |
| Питомцы | Специализация, новые кейсы по этапам, звёзды/слияние, синергии без обязательной удачи |
| Прокачка | Связать личную добычу, автоматизацию и питомцев; не множить параллельные деревья навыков |
| Мир | Фарм-зоны, открытие маршрутов, очистка, исследование, заказы, сюжетные цели |
| UI | Сравнение топоров, рюкзаков, петов, рабочих, понятные открытия и экономика |

## Черновая кривая прогресса

| Минуты | Этап | Ожидаемое ощущение |
|---|---|---|
| 0–20 | Прибытие, костёр, обучение | Понял цикл, первое улучшение |
| 20–60 | Хижина, переработка, рынок | Понимаю, как заработать и куда вложить |
| 60–120 | Рабочие, питомцы, топоры | Выбрал специализацию, первая автоматизация |
| 120–180 | Новые зоны, заказы, логистика | Сам выбираю стратегию |
| 180–300 | Продвинутое производство и мост | Большой итоговый проект, выход в главу II |

Это гипотеза, не расписание обязательных 300 минут. Цель 180–300 минут проверять разными стилями прохождения. Цены, время и уровни открытий рассчитываются в модели.

## SIM-01 — модель баланса до реализации

Таблица по этапам: доступные механики, уровень, время рубки/доставки/переработки, ресурсы/мин, монеты/мин, XP/мин, обязательные расходы, вложения, окупаемость, цены топоров/рюкзаков/паков/кейсов, время до полезного открытия. Сначала договориться о видах древесины, рецептах, деньгах и стадиях производства, затем выставлять числа.

Четыре сценария: ручная рубка, автоматизация, питомцы, смешанный. В каждом гарантированный проход без редких дропов, реалистичные перемещения, ограниченные склады, неидеальный игрок. Замерить долю ожидания и беготни, число повторов, время между значимыми открытиями. Проверить риск доминирующей стратегии и бесконечной пассивной экономики. Не увеличивать цены лишь ради времени. Сделать модели пересчитываемыми.

Проверить отдельные гипотезы:
- Уменьшает ли новый рюкзак число рейсов, а не только увеличивает объём обязательного гринда?
- Ощущаются ли топоры и новые виды деревьев различными?
- Игрок выбирает инвестицию по выгоде и предпочтению, а не потому, что один способ всегда лучший?
- Можно ли закончить главу без покупки дорогого пака и без легендарного питомца?
- Не открываются ли самые интересные механики только после финала?
